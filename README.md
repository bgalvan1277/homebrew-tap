# Brian Galvan's Homebrew tap

## No Bloat PDF

A free, 4.6 MB PDF viewer that opens instantly and makes zero network calls.
No ads, no accounts, no telemetry. MIT licensed.

    brew tap bgalvan1277/tap
    brew install --cask no-bloat-pdf

Or in one line:

    brew install --cask bgalvan1277/tap/no-bloat-pdf

Universal: separate Apple Silicon and Intel builds, both Developer ID signed
and notarized by Apple. Requires macOS 12 (Monterey) or later.

- Homepage: https://www.nobloatpdf.com
- Source: https://github.com/bgalvan1277/NoBloatPDF

To upgrade later:

    brew update && brew upgrade --cask no-bloat-pdf
